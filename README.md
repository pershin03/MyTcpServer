Серверная часть тестового задания в ООО СТЦ

Сервер для обработки запросов от нескольких клиентов с использованием многопоточности. Включен на прослушку клиентов. Каждое новое подключение обрабатывает в новом потоке. В качестве протокола обмена выбран текстовый формат JSON. Работа с сетью и БД организована стандартными средствами Qt.

## Технологический стек

*   **Язык**: C++17
*   **Фреймворк**: Qt 6.x (Core, Network, Sql)
*   **База данных**: SQLite (драйвер `QSQLITE`)
*   **Парсер JSON**: nlohmann/json (v3.11.3)
*   **Система сборки**: CMake 3.16+

---

## Инструкция по сборке и запуску

### Способ 1: Через Qt Creator (Рекомендуемый)
1. Откройте Qt Creator и выберите `File -> Open File or Project...`.
2. Выберите **корневой** `CMakeLists.txt`.
3. Настройте проект под комплект **Qt 6**.
4. Скомпилируйте и запустите (`Ctrl + R`). В консоли появится: `Сервер успешно запущен на порту: 12345`.

### Способ 2: Через командную строку (Консоль)
```bash
# Клонируем репозиторий
git clone https://github.com
cd ваш_репозиторий

# Создаем папку сборки и компилируем
mkdir build && cd build
cmake ..
cmake --build .

# Запуск сервера
./MyTcpServer
```
